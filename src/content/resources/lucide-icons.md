## Keep interface icons consistent

[Lucide](https://lucide.dev/icons/) is an open-source collection of SVG icons. Search by name, explore categories, and adjust appearance in the browser. Its [guide](https://lucide.dev/guide/) links to packages and explains sizing, styling, and accessibility.

## Put it into practice

Pick a small set for navigation and actions before building a page. Tell your AI assistant to use the same library throughout, import only the icons needed, and keep size and stroke width consistent.

## Choose clear labels

An icon can support a label, but an unfamiliar symbol can make an action harder to understand. Give icon-only buttons accessible names and check their readability at the size you actually use.
