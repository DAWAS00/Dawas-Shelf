## Work close to the code

Cursor is a code editor with AI assistance. A good first use is asking for an explanation of a small part of an unfamiliar project.

## A deliberate first change

Choose one reversible improvement, describe the behavior you want, and review the proposed changes. Run the project’s relevant checks before keeping the result.
