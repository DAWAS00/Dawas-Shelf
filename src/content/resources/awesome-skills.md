## Find instructions for a specific task

[Awesome Skills](https://awesomeskill.ai/) indexes agent skills sourced from GitHub. Search by name or keyword, browse categories and tags, and compare featured or recently added entries. The site presents skills for assistants including Claude Code, Codex, and ChatGPT.

## Start with the outcome you need

Look for a concrete task such as reviewing interface accessibility, researching a topic, or improving a development workflow. Open a candidate and read its original SKILL.md and repository instructions before deciding whether it fits your agent and project.

## Review before installing

Check the author, license, requested tools, scripts, and any external services. A directory listing or repository star count does not establish that a skill is safe or suitable. This shelf entry links to the discovery website; it does not install a skill.
