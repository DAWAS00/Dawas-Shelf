## Understand the connection

Model Context Protocol provides a way for AI applications to connect with tools and data. This repository is a starting point for reading about reference server implementations.

## Read before connecting

Follow each server’s documentation, review the access it needs, and check whether it is maintained. A reference example is not automatically a production service.

## Take one small step

Read the documentation for one server before running it. Understand the data it can access and the actions it can take in your chosen client.
